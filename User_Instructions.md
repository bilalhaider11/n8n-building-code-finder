# User Instructions — AI-Powered Building Code Lookup

## What This Tool Does
Returns the currently adopted building code for any US jurisdiction, along with the adopting authority, the state administrative-code reference, any local amendments, and 3–6 official sources you can verify against.

---

## Before You Start
Your n8n administrator must have imported `AI-Powered Building Code Lookup.json` and connected the **OpenAI** and **Serper API** credentials. If the form returns an error about a missing credential, ask them to complete setup.

---

## Step-by-Step

### 1. Open the Form
Open the form URL provided by your administrator. It ends in `/form/building-code-finder`.

You will see a form titled **Building Code Finder** with two fields.

### 2. Fill in the Inputs
| Field | What to enter |
|-------|---------------|
| **Location** | City + State, a ZIP code, or a full street address. Examples: `Renton WA`, `98168`, `4414 S 144th St`. |
| **Code Type** | Pick one from the dropdown: Building Code, Residential Code, Fire Code, Mechanical Code, Plumbing Code, or Electrical Code. |

Tips:
- Including the **state** (e.g., `Renton WA` instead of just `Renton`) gives more reliable results when city names are shared across states.
- The location must be 2–200 characters.

### 3. Submit
Click submit. The workflow runs for roughly 15–45 seconds while the AI agent issues web searches and assembles the answer.

### 4. Read the Result
The completion page shows:
- **Executive Summary** — 2–3 sentences on the current code status.
- **Key Adopted Code** — base code, adopting authority, and state administrative reference.
- **Local Amendments** — city-specific modifications, or "None found".
- **Official Sources** — a numbered list of links, each tagged `city`, `state`, `publisher`, or `other`. Open them to verify.

---

## Example
**Input**
```
Location:  Renton WA
Code Type: Fire Code
```

**Output (illustrative)**
- Base Code: *2021 International Fire Code, as amended*
- Adopting Authority: *Washington State Building Code Council*
- State Reference: *Chapter 51-54A WAC*
- Local Amendments: *Renton Municipal Code Title IV references state adoption with limited local additions.*
- Official Sources: 4–6 links to `wa.gov`, `rentonwa.gov`, and recognized publishers.

## Troubleshooting
| Problem | What to do |
|---------|------------|
| "Invalid location" error | Make sure the location is between 2 and 200 characters. |
| "Invalid code type" error | Use the dropdown; do not type a custom value. |
| "No verified sources" message in the result | Re-run with a more specific location (add the state, or use a city instead of a ZIP). |
| Run takes longer than ~60 seconds | The agent may be retrying searches. Wait for completion; the workflow caps the agent at 6 iterations and 5 searches. |

---

## Important Caveat
The result is generated by an AI research agent that grounds its claims in live web search. Always **verify the adopted code against the official jurisdiction website** before relying on it for permitting, design, or construction decisions. The footer of every result restates this.
